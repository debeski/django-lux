It follows System Settings' public page settings: title, meta description, theme, and the titlebar switch (the default header shows only when the public titlebar is on). Branding comes from Identity (logo, favicon) and the footer from Identity → Footer. The font is the language default from the registry, linked as a stylesheet. It emits no system configuration, URL map, preferences, strings or staff scripts, and no inline script, style or event handler, so it renders the same for every visitor and passes `script-src 'self'; style-src 'self'`. Pages that need the sidebar, the DjangoLux runtime or the dynamic modal extend `dlux/base.html` instead.
