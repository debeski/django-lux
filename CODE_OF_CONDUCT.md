# Code of Conduct

## Our Standards

This project is intended to be a practical, respectful space for building and maintaining `django-lux`.

Expected behavior includes:

- Be direct, constructive, and specific when discussing problems.
- Assume good intent, but keep technical claims evidence-based.
- Respect different experience levels, backgrounds, languages, and deployment contexts.
- Focus criticism on code, documentation, behavior, or design decisions rather than people.
- Avoid harassment, insults, threats, sexualized language, discriminatory remarks, and repeated unwanted contact.

## Scope

This code of conduct applies to project spaces, including issues, pull requests, discussions, security reports, documentation comments, and other maintainer-led communication channels.

## Enforcement

Maintainers may remove comments, close threads, reject contributions, block accounts, or take other reasonable actions when behavior harms the project or its contributors.

If you need to report unacceptable behavior, contact `debeski1@gmail.com`. Include relevant links, screenshots, timestamps, and any context that helps the maintainer understand what happened.

Reports will be reviewed as privately as practical. Maintainers will not require public confrontation as a condition of action.

## Attribution

This policy is inspired by common open source codes of conduct and adapted for this repository's small-maintainer workflow.
